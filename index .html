GC Session Tracker

In daily use by a clinical team
Problem
Counseling sessions were scheduled in Google Calendar, but every session had to be copied into the tracking spreadsheet by hand. Manual entry consumed hours of the team's time each week, entries were missed or inconsistent, and pulling data for reports was slow.
Built
An automatic Calendar-to-Sheets sync that adds new sessions, sorts them by date and time, numbers them, attaches each event's description as a hover note, and feeds live team dashboards.
Tools
Google Apps ScriptCalendar APIGoogle SheetsCOUNTIFS dashboards

Press "Sync calendar" to pull ten demo sessions from the calendar into the master sheet, just as the real script does. Rows are sorted by date and time and numbered automatically, and the month-to-date dashboards below update as they arrive. Hover an event title to see the calendar description. All names and IDs are fictional.

    GC Clinical Documentation Web App

    In daily use by a clinical team
    Problem
    Counselors documented each session in several places and wrote follow-up emails from scratch. Entering patient details by hand and drafting a summary for every case was time-consuming, and the summaries often came out with inconsistent alignment and formatting.
    Built
    A web app where each counselor selects the session type, enters session and patient details, records clinical and family history, and generates a formatted Genetic Counseling Summary, follow-up email note and test recommendation in one click. Each individual is saved as a row in the master sheet.
    Tools
    Google Apps ScriptHTML ServiceGoogle SheetsGmail drafts

    GC Activity Tracker Bot

    In daily use by a clinical team
    Problem
    Clinical interpretation queries and report reviews arrived by email and were easy to lose track of across the team.
    Built
    A Google Chat bot that logs each new item to a tracker sheet, posts it to the team space with one-click assignment and status buttons, and sends a morning digest and an end-of-day summary.
    Tools
    Google Apps ScriptGoogle Chat APIGmailTime-based triggers

    Variant Curation Toolkit

    In progress
    Problem
    Gathering population and clinical evidence for a variant means switching between several databases by hand before curation can even begin.
    Built
    A Python command-line tool that queries ClinVar and gnomAD for a variant and flags the ACMG/AMP evidence criteria worth reviewing, giving the curator a structured starting point. Final classification stays with the curator.
    Tools
    PythonClinVar APIgnomAD APIACMG/AMP
